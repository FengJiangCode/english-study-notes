## 方法论核心

长难句拆解分两步走，两步串联起来就是完整流程：

### 第一步：找连词和谓语动词（[01-找连词和谓语动词.md](01-拆解方法/01-找连词和谓语动词.md)）

**铁律：谓语动词数 = 连词数 + 1（主句）**

- 谓语动词四个标记：时态、语态、情态、助动词
- 最大陷阱：非谓语动词（to do / V-ing / V-ed）不是谓语
- 连词三大类：并列连词、从属连词、从句引导词
- 特别注意：连词省略（宾语从句省略 that、定语从句省略 that/which/who）

### 第二步：找主干和非主干（[02-找主干和非主干.md](01-拆解方法/02-找主干和非主干.md)）

**剥洋葱法**：从句首→句中→句末，逐层剥掉非主干，剩下的就是主干。

- **该剥的**：定语从句、状语从句、同位语从句、非谓语短语、介词短语、插入语
- **不该剥的**：主语从句、宾语从句、表语从句（它们是主干的一部分）

### 完整拆解七步法

```
① 圈谓语：找出所有谓语动词
② 圈连词：找出所有连词/引导词（含省略的）
③ 核对：谓语数 = 连词数 + 1
④ 切从句：根据连词标记每个从句的起止
⑤ 剥洋葱：把非主干用括号包起来
⑥ 提主干：剩下的就是主句的主谓宾
⑦ 理解：先翻译主干，再把非主干一层层加回
```

每道题的结构：
- **分析句子前**：思考题 + 重点词汇（音标 + 释义）

- **答案**：每步均有参考答案和解析

## 学习工作流

### 日常练习流程

1. **拿到原句**：不要急着看答案，先自己分析
2. **第一步**：圈谓语动词（小心非谓语的坑），数数量
3. **第二步**：圈连词，核对谓语数 = 连词数 + 1
4. **第三步**：切从句，标记从句边界
5. **第四步**：剥洋葱，砍掉非主干，提取主干
6. **第五步**：翻译，先主干后完整
7. **第六步**：对照答案，找出错误原因
8. **第七步**：回顾相关方法论，强化薄弱环节

### 错误分类与复盘

| 错误类型 | 原因 | 对应方法论 |
|------|------|------|
| 谓语找漏/找多 | 非谓语混淆、时态语态识别不准 | 01-找连词和谓语动词 §二 |
| 连词找漏 | 省略 that/which 没看出来 | 01-找连词和谓语动词 §三-⚠️ |
| 从句切错 | 并列谓语 vs 并列句分不清 | 01-找连词和谓语动词 §五 |
| 主干提错 | 把主语从句/宾语从句当非主干砍了 | 02-找主干和非主干 §七 |
| 插入语干扰 | 没识别出插入语 | 02-找主干和非主干 §3.2 |
| 翻译不准 | 非主干修饰关系搞混 | 02-找主干和非主干 §3.3 |

## 进度追踪

- 总题量：约 250+ 道
- 建议进度：每天 2-3 道，精做不贪多
- 重点年份：2010-2025 年（英语一/二分开后的真题）
- 早期真题（2002-2009）：适合入门练手，难度适中
- 近年真题（2020-2025）：贴近当前考试难度，重点关注

## 自测质量标准

每道题完成后，对照以下标准自检：

- [ ] 谓语动词全部找对，没有漏也没有多
- [ ] 连词全部找到，含省略的 that/which
- [ ] 谓语数 = 连词数 + 1 核对通过
- [ ] 每个从句边界标记正确
- [ ] 主干提取正确（主语+谓语+宾语/表语）
- [ ] 翻译先主干后完整，逻辑通顺
- [ ] 错题已复盘，错误原因已记录
