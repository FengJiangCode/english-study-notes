# 008 — 2002 年 Text 4 第 2 句

## 原句

> George Annas, chair of the health law department at Boston University, maintains that, as long as a doctor prescribes a drug for a legitimate medical purpose, the doctor has done nothing illegal even if the patient uses the drug to hasten death.

### Step 0 答案：谓语动词

**谓语动词（4 个）**：maintains / prescribes / has done / uses

**解析**：
- `maintains` — 主句谓语（三单）
- `prescribes` — as long as 条件状语从句的谓语（三单）
- `has done` — that 宾语从句的谓语（现在完成时）
- `uses` — even if 让步状语从句的谓语（三单）

> ⚠️ `to hasten death` = 不定式作目的状语，不是谓语。

### Step 1 答案：断开

**连词（3 个）**：that / as long as / even if

**断开标点**：逗号 `,`（多处：同位语前后各一个逗号、as long as 从句前后各一个逗号）

**解析**：
- `that` — 引导宾语从句，作 maintains 的宾语。⚠️ 宾语从句是主干，不砍
- `as long as` — 引导条件状语从句，嵌套在 that 宾语从句内部
- `even if` — 引导让步状语从句，嵌套在 that 宾语从句内部，位于句末

**核对**：谓语 4 个 = 连词 3 个 + 1 ✅

**分裂结构说明**：
`maintains that, as long as..., the doctor has done...` 中，`as long as` 从句插在 `that` 和宾语从句的主干 `the doctor has done...` 之间，把 that 宾语从句"劈开"了。这是考研常见的**分裂结构**（分隔结构）。

**从句切分**：
```
[主句: George Annas, (同位语: chair...University), maintains
  [宾从: that,
    [状从1: as long as a doctor prescribes a drug...],
    the doctor has done nothing illegal
    [状从2: even if the patient uses the drug to hasten death]
  ]
]
```

### Step 2 答案：简化

本句拆为 **4 件事**：

| # | 子句 | 类型 | 主干 | 非主干？ |
|------|------|------|------|------|
| 句 1 | George Annas, (chair...), maintains | 主句 | George Annas maintains | ❌ **主干** |
| 句 2 | that... the doctor has done nothing illegal | 宾语从句 | that doctor has done nothing | ❌ **主干** |
| 句 3 | as long as a doctor prescribes a drug... | 条件状语从句 | as long as doctor prescribes drug | ✅ 非主干 |
| 句 4 | even if the patient uses the drug... | 让步状语从句 | even if patient uses drug | ✅ 非主干 |

**主句主干**：`George Annas maintains` + `that doctor has done nothing`

**关键解析**：
- `chair of... University` = 同位语，夹在两个逗号之间，补充说明主语 George Annas 的身份
- `nothing illegal` = 不定代词 + 形容词，形容词修饰不定代词时**必须后置**。"nothing illegal" → "没有任何违法的事"
- `as long as` 从句把 that 和宾语从句主干劈开，先跳过 as long as 从句，找到 the doctor has done nothing 才能理解

### Step 3 答案：翻译

**主干译文**：乔治·安纳斯坚持认为……医生没有做任何违法的事

**完整译文**：波士顿大学健康法律系主任乔治·安纳斯坚持认为，只要医生开药是出于合理的医疗目的，那么即使病人使用该药物加速了死亡，医生的行为也没有违法。

**翻译技巧**：
- 同位语 `chair...` → 译为头衔前置："波士顿大学健康法律系主任乔治·安纳斯"
- `nothing illegal` → "没有任何违法的事"（形容词后置）
- `as long as` 从句劈开了 that 从句 → 翻译时先译 as long as，再译主句内容

## 核心收获

- [ ] 本句核心考点：**分裂结构** + **同位语** + **不定代词后置定语**
- [ ] `as long as` 从句插在 `that` 和宾语从句主干之间，把宾语从句劈开——这是分裂结构
- [ ] 两个逗号夹 `chair...` = 同位语，补充主语身份
