# 007 — 2002 年 Text 4 第 1 句

## 原句

> Although it ruled that there is no constitutional right to physician-assisted suicide, the Court in effect supported the medical principle of "double effect," a centuries-old moral principle holding that an action having two effects — a good one that is intended and a harmful one that is foreseen — is permissible if the actor intends only the good effect.

### Step 0 答案：谓语动词

**谓语动词（8 个）**：ruled / is / supported / is intended / is foreseen / is / intends

实际是 8 次出现：

| # | 谓语 | 所属从句 |
|------|------|------|
| ① | `ruled` | Although 让步状语从句 |
| ② | `is` | that 宾语从句（There be），在 Although 从句内部 |
| ③ | `supported` | 主句（逗号后） |
| ④ | `is intended` | that 定语从句，修饰 a good one |
| ⑤ | `is foreseen` | that 定语从句，修饰 a harmful one |
| ⑥ | `is` | that 宾语从句（holding 的宾语） |
| ⑦ | `intends` | if 条件状语从句 |

**一共 7 个谓语动词**，非谓语要排除：
- `holding` → 现在分词作后置定语，修饰 principle
- `having` → 现在分词作后置定语，修饰 action

> ⚠️ 检验：`holding` 前没有 be 动词，不是进行时；`having` 同理。

### Step 1 答案：断开

**连词（6 个）**：Although / that / that / that / that / if

**断开标点**：逗号 `,`（断开 Although 从句和主句）、破折号 `—`（插入同位语）

**解析**：
- `Although` — 引导让步状语从句
- `that`（第 1 个）— 引导宾语从句，作 ruled 的宾语
- `that`（第 2 个）— 引导宾语从句，作 holding 的宾语
- `that`（第 3 个）— 引导定语从句，修饰 a good one
- `that`（第 4 个）— 引导定语从句，修饰 a harmful one
- `if` — 引导条件状语从句

**核对**：谓语 7 个 = 连词 6 个 + 1 ✅

**从句切分**：
```
[状从: Although it ruled
  [宾从1: that there is no constitutional right to physician-assisted suicide]
],
[主句: the Court in effect supported the medical principle of "double effect,"
  [同位语: a centuries-old moral principle
    [分词定语: holding
      [宾从2: that an action
        [分词定语: having two effects
          — [同位语: a good one
              [定从1: that is intended]
            ]
          and [同位语: a harmful one
              [定从2: that is foreseen]
            ]
        ]
        is permissible
        [状从: if the actor intends only the good effect]
      ]
    ]
  ]
]
```

**嵌套层级**：
```
主句 (supported)
├── Although 状从 (ruled)
│   └── that 宾从 (is — There be)
└── 同位语 principle
    └── holding 分词定语
        └── that 宾从 (is permissible)
            ├── having 分词定语 → two effects
            │   ├── a good one → that 定从 (is intended)
            │   └── a harmful one → that 定从 (is foreseen)
            └── if 状从 (intends)
```

### Step 2 答案：简化

本句拆为 **7 件事**：

| # | 子句 | 类型 | 主干 | 非主干？ |
|------|------|------|------|------|
| 句 1 | Although it ruled... | 让步状语从句 | Although it ruled | ✅ 非主干 |
| 句 2 | that there is no constitutional right... | 宾语从句 | that there is right | ⚠️ 句 1 的宾语 |
| 句 3 | the Court... supported the medical principle... | **主句** | Court supported principle | ❌ **主干** |
| 句 4 | that an action... is permissible | 宾语从句 | that action is permissible | ⚠️ holding 的宾语 |
| 句 5 | that is intended | 定语从句 | that is intended | ✅ 非主干 |
| 句 6 | that is foreseen | 定语从句 | that is foreseen | ✅ 非主干 |
| 句 7 | if the actor intends only the good effect | 条件状语从句 | if actor intends effect | ✅ 非主干 |

**主句主干**：`Court supported principle`

### Step 3 答案：翻译

**主干译文**：法院支持原则

**完整译文**：尽管它（最高法院）裁定宪法没有赋予医生协助病人自杀的权利，但实际上法院支持"双重效果"的医疗原则，这个存在了好几个世纪的道德原则认为，具有双重效果（希望达到的好效果和可预见的坏效果）的行为是可允许的，只要行为实施者想要的仅仅是好效果。

**翻译技巧**：
- `in effect` → "实际上"（固定搭配，非"生效"）
- 破折号中的同位语 → 用括号处理："（希望达到的好效果和可预见的坏效果）"
- `holding that...` → 同位语+分词拆为独立句："这个原则认为……"
- `a centuries-old moral principle` → "这个存在了好几个世纪的道德原则"

## 核心收获

- [ ] 本句核心考点：**多级从句嵌套极限** — 7 个谓语、6 个连词、4 级嵌套
- [ ] `holding`、`having` = V-ing 非谓语作后置定语，分别修饰前面的名词，不是谓语
- [ ] 破折号之间的内容 = 插入性同位语，先跳过再回来理解
- [ ] `in effect` = "实际上"，不是"生效"
- [ ] 拆这种超级长句的诀窍：先数谓语和连词，核对铁律，心里有底再一层层剥
