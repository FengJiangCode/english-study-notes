# 006 — 2002 年 Text 3 第 1 句

## 原句

The OECD estimates in its latest Economic Outlook that,  

in its latest Economic Outlook 做状语修饰谓语 estimates，表示：在最后一期的【Economic Outlook】（经济展望）中预测

that 引导宾语从句 

OECD 在最后一期的【Economic Outlook】（经济展望）中预测

if oil prices averaged $22 a barrel for a full year, 

for a full year 时间状语：一整年

如果石油价格在一整年均价$22美元一桶


compared with $13 in 1998, 

相比1998年的13美元一桶

this would increase the oil import bill in rich economies by only 0.25%~0.5% of GDP.

这将会在富裕的经济体中增加石油进口指出，增加幅度仅仅是GDP的0.25%~0.5%

## 参考答案

<details>
<summary>点击展开答案</summary>

### Step 0 答案：谓语动词

**谓语动词（3 个）**：estimates / averaged / would increase

**解析**：
- `estimates` — 主句谓语（一般现在时三单）
- `averaged` — if 条件状语从句的谓语（过去式）
- `would increase` — that 宾语从句的谓语（情态动词 + do）

> ⚠️ `compared with` 是过去分词短语作状语（非谓语），不是谓语。检验：没有 be 动词，`compared` 单独出现 → 非谓语。

### Step 1 答案：断开

**连词（2 个）**：that / if

**断开标点**：逗号 `,`（两个逗号将 if 条件从句与其他内容隔开）

**解析**：
- `that` — 引导宾语从句，作 estimates 的宾语。⚠️ 宾语从句是主干成分，不砍
- `if` — 引导条件状语从句，嵌套在 that 宾语从句内部

**核对**：谓语 3 个 = 连词 2 个 + 1 ✅

**嵌套层级**：
```
主句: The OECD estimates...
└── [宾从: that ... this would increase ...
      └── [状从: if oil prices averaged $22 ...]
    ]
```

### Step 2 答案：简化

本句拆为 **3 件事**：

| 子句 | 类型 | 主干 | 是否非主干 |
|------|------|------|------|
| 句 1：The OECD estimates in its latest Economic Outlook... | 主句 | OECD estimates | ❌ **主干** |
| 句 2：that..., this would increase the oil import bill... | 宾语从句 | this would increase bill | ❌ **主干**（宾语从句不砍） |
| 句 3：if oil prices averaged $22 a barrel... | 条件状语从句 | if prices averaged $22 | ✅ 非主干 |

**主句主干**：`OECD estimates` + `that this would increase bill`

**关键解析**：
- `in its latest Economic Outlook` = 介词短语修饰 estimates，表示出处，非主干但翻译时保留——《经济展望》
- `if oil prices averaged $22...` = 条件状语从句嵌套在 that 宾语从句中，非主干
- `compared with $13 in 1998` = 过去分词短语作状语，修饰 if 从句，非主干
- `by only 0.25%~0.5% of GDP` = by 介词短语修饰 increase，表示幅度

### Step 3 答案：翻译

**主干译文**：经济合作与发展组织（OECD）估计……

**完整译文**：经济合作与发展组织（OECD）在其最新一期的《经济展望》中估计，如果油价全年平均为每桶 22 美元，对比 1998 年的（每桶）13 美元，这将使富裕国家的石油进口支出只增加 GDP 的 0.25% 至 0.5%。

**翻译技巧**：
- `in its latest Economic Outlook` → "在其最新一期《经济展望》中"（介词短语译为状语提前）
- `compared with` → "对比……"（非谓语比较状语，独立处理）
- `by only 0.25%~0.5%` → "只增加……0.25% 至 0.5%"（by 表示变化幅度）

## 核心收获

- [ ] 本句核心考点：**宾语从句嵌套条件状语从句** + **过去分词非谓语**
- [ ] `that` 引导宾语从句，that 宾语从句是主干，不砍
- [ ] `if` 引导条件状语从句嵌套在 that 从句内部，if 从句是非主干，砍掉
- [ ] `compared with` = 过去分词非谓语作状语，不是谓语
- [ ] `by + 数字` = "增加了……（幅度）"，考研经济类文章高频表达
