## 词根一：-liter-（文字 / 字母）

### 📖 词根故事

```
拉丁语 littera = 字母、文字。
liter + acy → 识字的能力 → literacy（读写能力）。
liter + ature → 文字作品 → literature（文学）。
```

> 核心逻辑：文字 → 读写能力 → 文学

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **literacy** /ˈlɪtərəsi/ | n. 读写能力；识字；有文化 | liter(文字)+acy→识字的能力 |
| **literature** /ˈlɪtrətʃər/ | n. 文学；文学作品；文献 | liter(文字)+ature→文字作品→文学 |

### 📝 必背例句

- The government promotes adult **literacy**. 政府推动成人扫盲。
- She is studying English **literature**. 她在学习英国文学。

## 词根二：-loc-（地点 / 放置）

### 📖 词根故事

```
拉丁语 locus = 地点、位置。
loc + al → 当地的 → local（本地的）。
loc + ate → 找到位置 → locate（定位、位于）。
al-(朝)+loc+ate → 分配位置 → allocate（分配）。
re-(重新)+place(放置) → 重新放置 → replace（替换）。
```

> 核心逻辑：地点 → 当地/定位/分配 ‖ 放置 → 替换

## 词根三：-log-（说话 / 逻辑 / 推理）

### 📖 词根故事

```
希腊语 logos = 说话、道理、推理。
log + ic → 说话的规则 → logic（逻辑）。
apo-(离开)+logy → 说开脱的话 → apology（道歉）。
ana-(按照)+logy → 按照同样的道理说 → analogy（类比）。
ana-(完全)+lyze → 完全分解开来说 → analyze（分析）。
cata-(下面)+log → 下面说的话 → catalog（目录）。
```

> 核心逻辑：说 → 逻辑/道歉/类比/分析/目录

## 词根五：-lus-/-lux-（光线 / 光明）

### 📖 词根故事

```
拉丁语 lux, lucis = 光。
il-(入)+lus+ion → 光线进入眼中→虚幻的景象 → illusion（幻觉）。
il-(入)+lustr+ate → 用光照亮→使明白 → illustrate（说明、加插图）。
lux + ury → 光鲜亮丽的东西 → luxury（奢侈、奢华）。
```

> 核心逻辑：光 → 幻觉(光影) → 说明(照亮) → 奢侈(光鲜)

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **illusion** /ɪˈluːʒ(ə)n/ | n. 幻觉；错觉；幻想 | il(入)+lus(光)+ion→光影入眼→幻觉 |
| **illusory** /ɪˈluːsəri/ | adj. 虚幻的；错觉的 | illusion→illus+ory |
| **illustrate** /ˈɪləstreɪt/ | v. 说明；阐明；加插图 | il(入)+lustr(光)+ate→用光照亮→说明 |
| **illustration** /ˌɪləˈstreɪʃ(ə)n/ | n. 插图；图解；说明 | illustrate+ion |
| **illustrator** /ˈɪləstreɪtər/ | n. 插图画家；说明者 | illustrate+or(人) |
| **luxury** /ˈlʌkʃəri/ | n. 奢侈；奢华；奢侈品 | lux(光)+ury→光鲜亮丽→奢侈 |
| **luxuriant** /lʌɡˈʒʊriənt/ | adj. 繁茂的；丰富的；奢华的 | luxury→luxur+iant |

### 🧩 记忆口诀

```
illusion 幻觉 illustrate 说明，

```

### 📝 必背例句

- The mirror creates an **illusion** of space. 镜子创造了一种空间幻觉。
- Let me **illustrate** my point with an example. 让我用一个例子来说明我的观点。
- They live a life of **luxury**. 他们过着奢侈的生活。
