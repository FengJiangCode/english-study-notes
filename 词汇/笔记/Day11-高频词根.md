## 词根一：-fac-/-fec-/-fic-/-feas-/-feat-/-fab-（做）

### 📖 词根故事

```
fac-/fec-/fic-/feas-/feat-/fab- 都来自拉丁语 facere（做）。
做事情 → 产生影响(affect) → 产生效果(effect) → 追求完美(perfect)
做得好 → 有效率(efficient) → 足够(sufficient) → 精通(proficient)
```

> 核心逻辑：做 → 做的结果、做的能力、做的方式

## 词根四：-fer-（拿、携带）

### 📖 词根故事

```
fer- = 拿、带、运
带过来 → 提供(offer)  带过去 → 转移(transfer)
拿来比 → 差异(differ)  拿来选 → 偏爱(prefer)
拿下去 → 受苦(suffer)  拿回来 → 参考(refer)
```
