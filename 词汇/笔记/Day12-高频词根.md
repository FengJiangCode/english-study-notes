## 词根一：-fess-/-phas-（说 / 强调）

### 📖 词根故事

```
-fess- 来自拉丁语 fateri（承认、说），profess 就是"公开说"→ 宣称专业。
-phas- 来自希腊语 phainein（显现），emphasize 就是"让重点显现出来"→ 强调。
两者在 Day 12 中合为一组：说出来的话需要强调。
```

> 核心逻辑：说(profess) → 专业(profession) → 强调(emphasize) → 重点(emphasis)

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **profession** /prəˈfeʃ(ə)n/ | n. 职业；专业 | pro(向前)+fess(说)→公开宣称→专业 |
| **professional** /prəˈfeʃən(ə)l/ | adj. 专业的 n. 专业人士 | profession+al |
| **professionalization** /prəˌfeʃənələˈzeɪʃ(ə)n/ | n. 职业化；专业化 | professional+ization(…化) |
| **emphasize** /ˈemfəsaɪz/ | v. 强调；着重 | em(使)+phas(显现)+ize→使显现→强调 |
| **emphasis** /ˈemfəsɪs/ | n. 强调；重点 | em(入)+pha(说)+sis→说到脑子里→强调 |

> 📝 拼写变体：emphasise (英式 -ise)；professionalisation = professionalization

### 📝 必背例句

- She is a **professional** actress. 她是专业女演员。
- I **emphasize** the importance of careful driving. 我强调小心驾驶的重要性。
- They put **emphasis** on developing economy. 他们把重点放在发展经济上。

## 词根二：-fid-（相信 / 信任）

### 📖 词根故事

```
拉丁语 fides = 信任、信仰。
对神 trust → faith（信仰）；对自己 trust → confident（自信）；
对机密 trust → confidential（机密的）；对联邦 trust → federal（联邦的）。
反过来，失去信任 → defy（蔑视）、deny（否认）。
```

> 核心逻辑：相信 → 信仰、自信、机密、联邦；不信 → 违抗、否认

## 词根八：-flu-/-fuse-（流 / 倒）

### 📖 词根故事

```
拉丁语 fluere = 流动，fundere = 倒、灌。
flu- → fluent（流利的）、fluid（流体）、influence（流入→影响）。
fluctu- → 来回流动 → fluctuate（波动）。
fuse- → confound+pour → confuse（流到一起→混淆）、refuse（往回倒→拒绝）。
整个家族都跟"流"有关：水流、气流、信息流、思想流。
```

## 词根九：-fore-（前 / 预先）

### 📖 词根故事

```
fore- = before（在前、预先）。
fore + see → 提前看到 → foresee（预见）。
fore + cast → 提前抛出→ forecast（预报）。
fore + most → 在最前面 → foremost（最重要的）。
```

> 核心逻辑：前 → 预见 → 预报 → 最重要的

---

## 词根十：-form-（形式 / 形成 / 构成）

### 📖 词根故事

```
拉丁语 forma = 形状、形式。
form 是最基础的"形式"：formal（正式的）→ 有形式的；inform（通知）→ 把形式告诉别人。
per(贯穿)+form → 从头到尾按形式做 → perform（表演、执行）。
re(再)+form → 重新塑形 → reform（改革）。
trans(跨)+form → 跨越形式 → transform（转变）。
con(一致)+form → 形式一致 → conform（符合）。
```

> 核心逻辑：形式 → 正式/非正式 → 表演/执行 → 改革/转变 → 符合
