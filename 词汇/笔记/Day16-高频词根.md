## 词根一：-habit-（居住 / 习惯）

### 📖 词根故事

```
拉丁语 habitare = 居住、持有。
habit（习惯）← 长期"持有"的行为模式。
in-(入)+habit → 住在里面 → inhabit（居住于）。
habitat（栖息地）← 动物居住的地方。
```

> 核心逻辑：居住 → 习惯 → 栖息地 → 居民

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **habitat** /ˈhæbɪtæt/ | n. 栖息地；生长地 | habit(居住)+at→住的地方 |
| **habitation** /ˌhæbɪˈteɪʃ(ə)n/ | n. 居住；住所 | habit+ation→居住的地方 |
| **inhabit** /ɪnˈhæbɪt/ | v. 居住于；栖息 | in(入)+habit(居住)→住进去 |
| **inhabitant** /ɪnˈhæbɪtənt/ | n. 居民；住户 | inhabit+ant(人)→居住的人 |

### 📝 必背例句

- The jungle is the natural **habitat** of tigers. 丛林是老虎的天然栖息地。
- The island is **inhabited** by about 500 people. 这个岛上住着大约500人。

## 词根二：-heir-/-herit-（继承）

### 📖 词根故事

```
拉丁语 heres = 继承人。
heir → 继承人 → heritage（遗产）→ inherit（继承）。
inherent = in(内)+her(继承)+ent → 生来就有的 → 固有的。
```

> 核心逻辑：继承 → 遗产 → 天生的 → 固有的

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **heritage** /ˈherɪtɪdʒ/ | n. 遗产；传统；继承物 | herit(继承)+age→继承的东西→遗产 |
| **inherit** /ɪnˈherɪt/ | v. 继承；经遗传而得 | in(入)+herit→进入继承→继承 |
| **inheritor** /ɪnˈherɪtər/ | n. 继承人；后继者 | inherit+or(人) |
| **inherent** /ɪnˈhɪrənt/ | adj. 固有的；内在的；天生的★ | in(内)+her(继承)+ent→天生就有的 |
| **inherently** /ɪnˈherəntli/ | adv. 天性地；固有地；内在地 | inherent+ly |

### 📝 必背例句

- We must preserve our cultural **heritage**. 我们必须保护文化遗产。
- She **inherited** a large fortune from her father. 她从父亲那里继承了一大笔财产。
- There are **inherent** risks in this investment. 这项投资有固有的风险。

## 词根三：-hes-/-her-（黏 / 粘）

### 📖 词根故事

```
拉丁语 haerere = 黏住、粘附。
hes- → 黏在原地不动 → hesitate（犹豫）← 脚步被"黏住"了。
ad-(朝)+here → 黏上去 → adhere（粘附、坚持）。
co-(一起)+here → 黏在一起 → cohere（连贯、一致）。
```

> 核心逻辑：黏 → 犹豫(脚黏住了) → 粘附 → 连贯

## 词根四：-hibit-（拿 / 保持）

### 📖 词根故事

```
拉丁语 habere = 持有、拿。
ex-(出)+hibit → 拿出去 → exhibit（展览、展示）。
pro-(前)+hibit → 在前面拿住 → prohibit（阻止、禁止）。
```

> 核心逻辑：拿 → 拿出来(展览) / 拿住不让走(禁止)

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|

### 📝 必背例句

## 词根五：-hind-（后面 / 阻碍）

### 📖 词根故事

```
hind = 后面的。
hind → behind（在后面）→ hinder（使落后→阻碍）。
hint（暗示）→ 不直接说，从后面给线索。
hamper（阻碍）→ 与 hinder 近义，联想记忆。
```

> 核心逻辑：后面 → 阻碍 → 暗示(从后面给线索)

---

humble（谦卑的）→ 把自己放低到"土"里。
humid（潮湿的）→ 土里有水气。
humiliate（羞辱）→ 把人踩到土里。
humor（幽默）→ 古代医学中的"体液"，引申为气质→幽默。

## 词根八：-hypo-（下面 / 低于）

### 📖 词根故事

```
希腊语 hypo = 在…下面、低于。
hypo + thesis(放置) → 放在下面 → hypothesis（假设）← 还没浮上来的想法。
hypo + crisy(判断) → 在下面判断 → hypocrisy（虚伪）← 表面一套、底下一套。
```

> 核心逻辑：下面 → 假设(底层想法) → 虚伪(表里不一)

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **hypothesis** /haɪˈpɑːθəsɪs/ | n. 假设；假说 | hypo(下)+thesis(放)→放在下面的想法→假设 |
| **hypocrisy** /hɪˈpɑːkrəsi/ | n. 虚伪；伪善 | hypo(下)+crisy(判断)→底下判断→表里不一 |
| **hypocritical** /ˌhɪpəˈkrɪtɪk(ə)l/ | adj. 虚伪的；伪善的 | hypocrisy+tical→虚伪的 |

### 📝 必背例句

- Scientists tested the **hypothesis** through experiments. 科学家通过实验验证了这个假说。
- It's **hypocritical** to say one thing and do another. 说一套做一套是虚伪的。
