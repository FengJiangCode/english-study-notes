## 词根一：-im-/-in-（前缀：里 / 进入）

### 📖 词根故事

```
拉丁语 in- = 在…里面、进入。
in- 是最常见的前缀之一，表示"往里、进入、在内部"。
imprison = im+prison → 放进监狱 → 监禁。
inborn = in+born → 出生就在里面的 → 天生的。
invest = in+vest → 穿进去 → 投入资金 → 投资。
intrude = in+trude → 往里面推 → 侵入。
```

> 核心逻辑：往里/进入 → 监禁/天生/内部/投资/侵入

## 词根二：-im-/-in-（前缀：否定 / 不）

### 📖 词根故事

```
同一个 in-/im- 前缀，也可以表示"不、否定"。
in + dignant(worthy) → 觉得不值得 → indignant（愤慨的）。
im + pair(相等) → 不相等 → impair（损害、削弱）。
in + satiable(satisfy) → 不能满足的 → insatiable（贪得无厌的）。
```

> 核心逻辑：不/否定 → 愤慨(觉得不值) → 损害(不平等) → 不知足

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **indignant** /ɪnˈdɪɡnənt/ | adj. 愤慨的；愤怒的 | in(不)+dign(值得)+ant→觉得不值得→愤慨 |
| **indignation** /ˌɪndɪɡˈneɪʃ(ə)n/ | n. 愤慨；义愤 | indignant的名词 |
| **impair** /ɪmˈper/ | v. 损害；削弱；损伤 | im(不)+pair(相等)→使不等→损害 |
| **impairment** /ɪmˈpermənt/ | n. 损害；损伤；障碍 | impair+ment |
| **insatiable** /ɪnˈseɪʃəb(ə)l/ | adj. 贪得无厌的；无法满足的 | in(不)+satiable(可满足的)→不知足 |

### 📝 必背例句

- She was **indignant** at the unfair treatment. 她对不公平的待遇感到愤慨。
- Smoking can **impair** your health. 吸烟会损害你的健康。


## 词根五：-jud-/-jur-（判断 / 审判 / 法律）

### 📖 词根故事

```
拉丁语 judex = 法官，jus = 法律、权利。
judge → 做判断的人 → judgment（判断力）。
jury（陪审团）→ 做判断的一群人。
pre-(前)+judice → 提前判断 → prejudice（偏见）。
jurisdiction → juris(法律)+diction(说)→ 法律说了算的范围→管辖权。
```

> 核心逻辑：判断 → 法官/陪审团 → 偏见(提前判断) → 司法管辖

```
ad-(朝)+just → 朝着正确的方向调 → adjust（调整）。
```
