## 词根一：-gen-/-gn-/-gene-（基因 / 产生 / 出生）

### 📖 词根故事

```
希腊语 genos = 出生、种族、种类。
gen- 是英语中最"高产"的词根之一：
- gene（基因）→ 生命的基本单位 → genetics（遗传学）
- generate（产生）→ 让事物"出生"→ generator（发电机）
- genius（天才）→ 与生俱来的才能 → ingenious（聪明的）
- genuine（真正的）→ 天生的、非人造的 → generous（慷慨的）→ 出身高贵的品质
- gender（性别）→ 天生的分类
```

> 核心逻辑：出生 → 基因/遗传 → 产生/创造 → 天才/天赋 → 真实/慷慨

## 词根二：-geo-（大地 / 土地）

### 📖 词根故事

```
希腊语 ge = 大地、土地。
geo + graphy(写/画) → 描绘大地 → geography（地理学）。
geo + logy(学科) → 研究大地的学科 → geology（地质学）。
geo + metry(测量) → 测量大地 → geometry（几何学）。
```

> 核心逻辑：大地 → 地理/地质/几何——都是研究大地的学科

---

## 词根三：-gl-（光线 / 光明 / 视觉）

### 📖 词根故事

```
gl- 开头的词多与"光、看、光滑"相关：
- glance/glimpse（一瞥）→ 光线一闪而过
- glare（强光/怒视）→ 刺眼的光
- glory/glorious（光荣/辉煌）→ 光芒四射的荣耀
- glow（发光/发热）→ 温暖的光芒
- gloom（阴暗/忧郁）→ 光线被遮住 → 心情变暗
- glamor（魅力）→ 闪闪发光的吸引力
- grammar（语法）→ 虽不属 gl- 族，但与 glamour 形似，合并记忆
```

> 核心逻辑：光 → 看/瞥 → 闪耀/荣耀 → 发光 → 阴暗(缺光) → 魅力(发光)

## 词根四：-gn-/-cogn-（知道 / 认识）

### 📖 词根故事

```
拉丁语 gnoscere / cognoscere = 知道、认识。
co-(一起)+gn(知道) → 一起知道 → cognitive（认知的）。
re-(再)+cognize → 再次认识 → recognize（认出、承认）。
dia-(通过)+gnose → 通过认识来区分 → diagnose（诊断）。
```

> 核心逻辑：知道 → 认知 → 识别/认出 → 诊断

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **recognize** /ˈrekəɡnaɪz/ | v. 认出；意识到；承认 | re(再)+cogn(知道)+ize→再次认识→认出 |
| **recognition** /ˌrekəɡˈnɪʃ(ə)n/ | n. 认出；识别；承认；赞誉 | recognize的名词 |
| **unrecognized** /ʌnˈrekəɡnaɪzd/ | adj. 未被认出的；不被承认的 | un+recognized |
| **diagnose** /ˌdaɪəɡˈnəʊs/ | v. 诊断；判断 | dia(通过)+gnose(知道)→通过知道来区分 |
| **diagnosis** /ˌdaɪəɡˈnəʊsɪs/ | n. 诊断；诊断结果 | diagnose的名词 |
| **cognitive** /ˈkɑːɡnətɪv/ | adj. 认知的；认识的 | co(一起)+gn(知道)+itive→一起知道的→认知的 |

> 📝 拼写变体：recognize (美) = recognise (英)

### 🧩 记忆口诀

```
recognize 认出 diagnosis 诊断，
cognitive 认知记心间。
```

### 📝 必背例句

- I could hardly **recognize** him after 10 years. 十年后我几乎认不出他了。
- The doctor **diagnosed** the illness as cancer. 医生诊断此病为癌症。
- Linguistics is an important branch in **cognitive** science. 语言学是认知科学的一个重要分支。
