## 词根一：-man-/-manu-（手）

### 📖 词根故事

```
拉丁语 manus = 手。
manu + facture(做) → 用手做 → manufacture（制造）。
manu + script(写) → 用手写的 → manuscript（手稿、原稿）。
mani + pul(拉)+ate → 用手拉 → manipulate（操纵、操作）。
man + ner → 手的方式 → manner（方式、举止）。
man + fest(触) → 用手能触到的 → manifest（明显的、表明）。
```

> 核心逻辑：手 → 制造/手稿/操纵/方式/表明

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **manipulate** /məˈnɪpjuleɪt/ | v. 操纵；操作；控制 | mani(手)+pul(拉)+ate→用手拉→操纵 |
| **manipulation** /məˌnɪpjuˈleɪʃ(ə)n/ | n. 操纵；操作 | manipulate+ion |
| **manipulator** /məˈnɪpjuleɪtər/ | n. 操纵者；操作者 | manipulate+or(人) |
| **manufacture** /ˌmænjuˈfæktʃər/ | v./n. 制造；生产 | manu(手)+fact(做)+ure→用手做→制造 |
| **manufacturer** /ˌmænjuˈfæktʃərər/ | n. 制造商；生产商 | manufacture+er(人) |
| **manufacturing** /ˌmænjuˈfæktʃərɪŋ/ | n. 制造业；生产 | manufacture+ing |
| **manifest** /ˈmænɪfest/ | v. 表明；显示 adj. 明显的 | mani(手)+fest(触)→用手能触到→明显 |
| **manifesto** /ˌmænɪˈfestəʊ/ | n. 宣言；声明 | manifest+o→公开表明→宣言 |
| **manuscript** /ˈmænjuskrɪpt/ | n. 手稿；原稿；底稿 | manu(手)+script(写)→手写的→手稿 |

### 📝 必背例句

- The company **manufactures** electronic products. 这家公司制造电子产品。
- The symptoms **manifest** themselves in various ways. 症状以各种方式表现出来。

## 词根二：-mand-（命令 / 委托）

### 📖 词根故事

```
拉丁语 mandare = 命令、委托。
de-(完全)+mand → 强烈命令 → demand（要求、需求）。
com-(一起)+mand → 一起命令 → command（命令、指挥）。
mand + ate → 被命令的事 → mandate（授权、命令）。
mand + atory → 命令的 → mandatory（强制性的）。
```

> 核心逻辑：命令 → 要求/指挥/授权/强制

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **demand** /dɪˈmænd/ | n./v. 要求；需求；需要 | de(完全)+mand(命令)→强烈命令→要求 |
| **command** /kəˈmænd/ | n./v. 命令；指挥；掌控 | com(一起)+mand→一起命令→指挥 |
| **mandate** /ˈmændeɪt/ | n./v. 授权；命令；委托 | mand(命令)+ate→命令→授权 |
| **mandatory** /ˈmændətɔːri/ | adj. 强制性的；命令的 | mandate+ory→命令的→强制的 |

### 📝 必背例句

- The workers **demanded** higher wages. 工人要求更高的工资。
- Attendance is **mandatory** for all students. 所有学生必须参加。

## 词根三：-mark-（标记 / 边界）

### 📖 词根故事

```
mark 本身 = 标记、记号。
land + mark → 地的标记 → landmark（地标、里程碑）。
marg- = mark 的变体 → margin（边缘、页边空白）。
re-(再)+mark → 再次标记 → remark（评论、注意到）。
remark + able → 值得注意的 → remarkable（非凡的、显著的）。
```

> 核心逻辑：标记 → 地标/边界/评论/非凡

## 词根九：-merge-/-mers-（沉没 / 浸入）

```
拉丁语 mergere = 沉没、浸入。
merge → 融合在一起（沉到一起）。
e-(出)+merge → 从沉没中出来 → emerge（出现、浮现）。
emergency → 突然出现的事 → 紧急情况。
im-(入)+merse → 沉入进去 → immerse（沉浸、浸入）。
im-(入)+mense → 沉入无法测量 → immense（巨大的、无限的）。
```

> 核心逻辑：沉/浸 → 融合/浮现/紧急/沉浸/巨大

```
merge 合并 emerge 浮现，

```
