## 词根一：-grad-/-gress-/-gred-（走 / 步 / 级）

### 📖 词根故事

```
拉丁语 gradi = 走、步行，gressus = 步伐。
走一步 → grade（等级、年级）→ 每一步都是一个级别。
往上走 → upgrade（升级）；往下走 → degrade（降级、退化）。
往前走 → progress（进步）；往外走 → aggressive（侵略性的）。
往一起走 → congress（代表大会）→ 走到一起开会。
往回走 → regret（后悔）→ 走回去想→懊悔。
走进去 → ingredient（成分）→ 走进混合物的东西。
走到一起 → integrate（整合）→ 走到一起成为整体。
```

> 核心逻辑：走 → 等级/升级 → 前进/攻击 → 会议 → 后悔 → 整合

## 词根二：-graph-（写 / 描绘）

### 📖 词根故事

```
希腊语 graphein = 写、画、记录。
bio(生命)+graphy(写) → 写一个人的一生 → biography（传记）。
auto(自己)+bio+graphy → 自己写自己的一生 → autobiography（自传）。
demo(人民)+graphy(写) → 记录人民的数据 → demography（人口统计学）。
```

> 核心逻辑：写/记录 → 传记 → 人口统计

## 词根三：-grat-（高兴 / 感激 / 愉悦）

### 📖 词根故事

```
拉丁语 gratus = 高兴的、感激的。
grateful = 充满感激的 → gratitude（感激之情）。
gratify = 使高兴 → gratification（满足、喜悦）。
grace 也是同源词：受到恩惠 → 感恩 → 优雅（感恩的态度）。
```

> 核心逻辑：高兴 → 感激 → 感谢 → 满足

## 词根四：-grav-（重 / 沉重）

### 📖 词根故事

```
拉丁语 gravis = 重的、沉重的。
grave（严重的、坟墓）→ 最"沉重"的事 → 死亡。
ag-(朝)+grav(重)+ate → 使变重 → aggravate（加重、恶化）。
grieve（悲伤）→ 心情很"沉重" → grief（悲痛）。
```

> 核心逻辑：重 → 严重/加重 → 悲伤/悲痛

---

### 🔗 单词家族

| 单词 | 释义 | 记忆线索 |
|------|------|------|
| **grave** /ɡreɪv/ | adj. 严重的；严肃的 n. 坟墓★ | 熟词僻义：严重的（非"坟墓"） |
| **graveyard** /ˈɡreɪvjɑːrd/ | n. 墓地 | grave+yard(院子)→坟墓院子→墓地 |
| **aggravate** /ˈæɡrəveɪt/ | v. 加重；恶化；激怒 | ag(朝)+grav(重)+ate→使变重→加重 |
| **grieve** /ɡriːv/ | v. 悲伤；伤心；使悲伤 | griev(沉重)→心情沉重→悲伤 |
| **grievance** /ˈɡriːvəns/ | n. 不满；委屈；抱怨 | grieve+ance→悲伤的事→委屈 |
| **grief** /ɡriːf/ | n. 悲痛；悲伤；不幸 | grieve的名词→悲痛 |

### 🧩 记忆口诀

```
grave 严重 aggravate 加重，
grieve 悲伤 grief 是悲痛。
```

### 📝 必背例句

- The situation is very **grave**. 局势非常严峻。
- The cold weather **aggravated** his illness. 寒冷的天气加重了他的病情。
- She **grieved** over her husband's death. 她为丈夫的去世而悲伤。
